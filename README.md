# Counting From 1 to 10 — School Assignment

A tiny beginner Python exercise for my computing class: practice a
`for` loop by printing the numbers 1 through 10, and (bonus part)
their times-table row for 1-10 as well.

## How to run

```bash
python scripts/count.py
```

## What it teaches

- `for` loops and `range()`
- printing with `print()`
- nested loops (the bonus times table)
